## 📌 Problem Statement

A restaurant aggregator aims to revamp its B2C platform using intelligent automation to identify **star-performing restaurants** and generate personalized recommendations for users.

To achieve this, it is essential to analyze restaurant performance based on:

- Customer Ratings  
- Number of Votes  
- Online Delivery Availability  
- Table Booking Facility  
- Cost for Two  
- Cuisine Variety  
- Geographic Distribution  

The goal is to understand the key factors influencing customer satisfaction and engagement.

---

## 🎯 Project Objective

Build a data-driven analytical solution to:

- Identify star restaurants  
- Analyze customer behavior patterns  
- Evaluate service-driven factors affecting ratings  
- Support automated restaurant recommendation systems  

---

## 🧰 Tools & Technologies Used

- Python (Pandas, NumPy, Matplotlib, Seaborn)  
- Tableau  
- Microsoft Excel  

---

## 📂 Dataset Information

Two datasets were used:

1. **Zomato Dataset**
   - Contains 19 attributes such as restaurant name, city, cuisines, ratings, votes, cost, delivery, etc.

2. **Country Code Dataset**
   - Contains country code and corresponding country names

---

## 🔍 Data Preprocessing

- Inspected dataset structure  
- Checked for missing values  
- Identified and removed duplicate records  
- Merged both datasets for analysis  

---

## 📊 Exploratory Data Analysis (EDA)

- Analyzed geographical distribution of restaurants  
- Identified cities with maximum and minimum restaurants  
- Evaluated franchise national presence  
- Calculated ratio of restaurants offering table booking  
- Calculated percentage of restaurants providing online delivery  
- Compared number of votes between delivery and non-delivery restaurants  
- Identified top 10 cuisines across cities  
- Analyzed cost distribution among restaurants  
- Studied rating distribution  
- Examined factors affecting restaurant ratings  

---

## 📈 Key Business Insights

- Restaurants offering **online delivery receive higher customer engagement**

- Moderate pricing strategy shows **better customer ratings**

- Multi-cuisine restaurants attract higher customer votes

- Availability of services such as delivery and booking positively impacts ratings
